# sockettcp

tcp/ip server/clinet c library with ssl/tls support.

This is code originally from the [Civitweb project](https://github.com/civetweb/civetweb)  where the tcp/ip functionality was lifted out. This was done because of the need for a MIT license in the [VSCP project](https://vscp.org). Today the code is lifted out because we use Mongoose instead which is the mother of this code from the beginning even before Civitweb.

The code is still very capable but is no more being updated.
